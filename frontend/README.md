# Argus frontend

React + TypeScript + Vite showcase UI. See the root `README.md`'s
"Frontend" section for the full rationale (why this reads a precomputed
JSON export instead of a live API) and setup steps.

Quick start (from the repo root):

```
PYTHONPATH=. python scripts/export_dashboard_data.py
cd frontend
npm install
npm run dev
```
